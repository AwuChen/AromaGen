# AromaGen data directory

## What ships in the public repository

| Path | In git? | Purpose |
|------|---------|---------|
| `samples/dialogue_sample.jsonl` | Yes | Schema example only (synthetic row) |
| `learned_examples.json.example` | Yes | Copy to `learned_examples.json` or let the backend create `[]` |
| `dialogue/dialogue_*.jsonl` | **No** (gitignored) | Local session logs from demos |
| `interaction_log.jsonl` | **No** | Local RAG / feedback log (from optional frontend logging) |
| `interaction_log_embeddings.json` | **No** | Embedding cache for retrieval |
| `learned_examples.json` | **No** | Accepted compositions for ICL at compose time |
| `exports/training_*.jsonl` | **No** | Generated by `scripts/export_training_data.py` |

Lab production corpora (demo dialogue, interaction feedback, embeddings) are **not** part of the open-source release. See [`docs/PUBLIC_RELEASE.md`](../../docs/PUBLIC_RELEASE.md).

## Event types (`dialogue/*.jsonl`)

| Event | Fields of interest |
|-------|-------------------|
| `transcribe` | `human_input` (Whisper transcript) |
| `compose` | `human_input`, `response.scent_sequence`, `response.justification` |
| `feedback` | `request.latest_feedback`, revised sequence |
| `accept` | final sequence saved to example bank |
| `describe_image` | image → sensory text → compose |

## Local setup

```bash
cp aromagen/data/learned_examples.json.example aromagen/data/learned_examples.json
# optional: enable dialogue logging (default true) writes new files under dialogue/
```

Regenerate training exports after you collect local sessions:

```bash
python scripts/export_training_data.py
```

## Privacy

Do not commit `.env`, dialogue logs, interaction logs, or study CSVs. Review [`docs/PUBLIC_RELEASE.md`](../../docs/PUBLIC_RELEASE.md) before pushing.
