Per-odorant review

Click an odorant to see which requests used it. Dominance is computed within each individual response first (which odorant had the single highest ratio in that specific composition -- valid, since ratios in one response sum to ~1), then aggregated across repeats of the same request text by majority vote of those per-instance winners. Load-bearing = won the majority of repeats; supporting = did not. Requests with no logged ratio — predating the ratio field (before 2026-07-31), or from the external batch — are listed separately, collapsed by default.

Cards below are ordered by total ranking score — the sum of each odorant's rank (1 = best, 11 = worst) across the four metadata metrics (exact-match accuracy, unique requests, load-bearing requests, non-load-bearing requests). Ties within a metric all take the worst rank in the tied group. Lowest total score first: that odorant performs most consistently well across all four; highest total score last: the weakest all-around candidate.
